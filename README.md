# 鹈鹕环岛记 · Pelican Isle Ride

> 🚴 **[▶ 点这里直接试玩](https://bayshier.github.io/pelican-isle/)** —— 打开即玩,无需安装(WebGL2 浏览器即可,建议 Chrome / Edge / Safari;桌面体验最佳,手机有触屏按键)

**纯 Three.js(r160)手写,约 3300 行代码,零模型 / 零贴图 / 零音频文件**——你看到的一切,都是代码在浏览器里现场"长"出来的。

## 它是一座什么样的岛

- **环岛公路 + 支路**,穿村庄、上山岗、绕海角,路面和草地抓地力不同
- **渔火村**:10 栋小屋、水井、市集摊、广场串灯——入夜窗火一盏盏亮起
- **灯塔海角**:红白灯塔,夜间双光束旋转扫海
- **主峰**(雪线观景台)与山坡上三台旋转的风力发电机、山岗荷兰风车
- **观海栈桥**与随浪摇的帆船、沙滩篝火
- **317 米跨海大桥**,通向离岛「鹈鹕岩」
- 两只热气球环岛漂、海鸥编队、蝴蝶(白天)、萤火虫(夜里)
- **15 分钟一整天的昼夜循环**:晨光、正午、金色黄昏、星空与月光
- 31 条金色小鱼散落全岛,车筐会真的被装满

## v2:赛璐璐渲染(2026-11-25)

第一版是偏写实的 PBR:物理天空、法线贴图海面、颗粒很重的电影感调色。第二版把它整体抬成了动画电影式的卡通画面:

- **全场卡通着色**:`js/style.js` 给每个标准材质注入三阶色阶 + 边缘光,投影边和色阶边天然重合;车架、镀铬件、金色小鱼这类高金属度材质留在 PBR,保住金属反光。
- **墨线描边**:整场景用「法线材质」再画一遍,在屏幕空间做深度 + 法线边缘检测;近处清晰、远处淡出,草丛和花不描。
- **新天空**:一整块程序化穹顶着色器——天顶 / 地平线渐变、朝阳侧染暖、成层的积云、日轮、月亮、程序化星空,全部按太阳高度查同一张调色板。
- **新海面**:四组解析正弦波代替滚动法线贴图(旧版远处会闪成一片),深浅渐变、天色反射、成片浪线、推向岸边的泡沫带,泡沫的白跟着天色走。
- **手感**:逻辑改成固定 60Hz 步长(高刷屏不再加速);落地扬尘 + 镜头轻沉;鹈鹕有了黑翼尖和随风飘的红领巾。
- **画质三档**:高(描边 + 泛光)/ 中(去描边)/ 低(去泛光),`Q` 键切换;开局几秒内带不动会自动降档。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ · S / ↓ | 骑行 / 刹车 |
| A D / ← → | 转向 |
| Shift | 漂移(扬尘) |
| Space | 小跳 |
| C | 视角:追尾 → 电影低机位 → 环绕(拖拽旋转 / 滚轮缩放) |
| T | 时间流速:1× → 40× → 暂停(用 40× 看日落!) |
| F | 车铃 |
| M / P | 小地图 / 拍照模式(黑边 + 纯净画面) |
| Q | 画质:高 → 中 → 低 |
| R / N | 回村 / 静音 |

触屏设备会出现屏幕按键:左下转向,右下油门、刹车、跳。

## 本地运行

```bash
git clone https://github.com/bayshier/pelican-isle.git
cd pelican-isle
node server.js        # 或任意静态服务器
# 打开 http://localhost:8642
```

Three.js 已精简打包在 `libs/three/`,离线可跑,无 npm install。
开发时别用 `python -m http.server`:它不发缓存头,Chrome 会对 ES 模块做启发式缓存,改完刷新可能还在跑旧代码。

## 它是怎么做的(技术速览)

- **一个高度函数统治全岛**:`terrainHeight(x, z)` 纯函数(simplex 噪声域扭曲海岸线 + 掩膜 + 主峰 / 离岛高斯 + 台地 + 桥面走廊),地形网格、植被散布、建筑地基、骑行物理、桥面全部查它——所以跨海大桥直接"写"进高度场,车轮天然贴桥。
- **自定义海面 shader**:解析波纹法线按视距压平,菲涅尔映天色,太阳高光近锐远粗;岸边泡沫和浅滩透明来自一张烘焙高度图(`DataTexture`),离岸自动渐隐。
- **昼夜 = 一份调色板**:按太阳高度角插值的 5 个关键帧,同时驱动雾色、水色、天空、云、阳光和半球光;环境反射只留给金属件,太阳挪够了才重烘。
- **卡通着色与描边**:`style.js` 串在材质原有的 `onBeforeCompile`(风摆)后面,而不是覆盖它;描边预通道用同一份风摆,树冠的线和本体才对得上。
- **6000+ 植被全是 InstancedMesh**:顶点色 + `aSway` 属性,`onBeforeCompile` 注入风摆;建筑同理,窗户单独实例化,夜晚一行代码全村亮灯。
- **鹈鹕蹬腿 = 双骨 IK**:踏板位置由曲柄角解析算出,膝关节平面圆交求解,骨骼用 `setSegment` 摆放;翅膀搭在车把上随转向摆动,压弯人和车一起倾。
- **后期**:HalfFloat MSAA → 墨线描边 → UnrealBloom(线性 HDR 下阈值必须 >1,第一坑)→ 调色 → ACES 输出。
- **音频零文件**:WebAudio 合成风(随车速)、浪(随离岸距离)、车铃与收集音。

测试钩子挂在 `window.__G`:`step(n)` 确定性步进(后台标签 rAF 冻结时也能跑)、`setTime(h)`、`applyQuality(i)`、`stats()`(含着色器编译错误数)。
