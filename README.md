# 鹈鹕环岛记 · Pelican Isle

一只戴水手帽的鹈鹕,骑着红色自行车,环游一座程序化生成的热带大岛。纯 Three.js(r160)手写,无任何模型/贴图资源文件 —— 所有几何、颜色、水面、天空均为代码实时生成。

## 运行

```bash
cd pelican-isle
node server.js        # 或任意静态服务器,如 python3 -m http.server
# 打开 http://localhost:8642
```

## 岛上有什么

- **渔火村**:10 栋小屋、水井、市集摊、串灯、路灯,入夜窗火渐亮
- **灯塔海角**:红白灯塔,夜间旋转光束
- **主峰观景台**(雪山之巅)、**山岗风车**、山顶三台风力发电机
- **观海栈桥**与帆船、沙滩篝火
- **跨海大桥**通往离岛「鹈鹕岩」
- 两只热气球、海鸥编队、蝴蝶、夜间萤火虫
- 环岛公路 + 支路,沿途 40 条金色小鱼等待收集(车筐真的会装满)
- 15 分钟一整天的昼夜循环:晨光、白昼、金色黄昏、星空与月光

## 技术

- 地形:2D simplex 噪声高度场(域扭曲海岸线 + 主峰/离岛高斯隆起 + 村庄/海角台地),320×320 网格顶点色
- 海面:自定义 shader —— 双层滚动程序法线、菲涅尔反射天空、太阳/月亮高光、基于烘焙高度图的岸边泡沫与浅滩透明
- 天空:三牛 Sky 物理天空 + PMREM 环境光照,昼夜配色关键帧插值,玩家跟随式阴影相机
- 植被:全部 InstancedMesh(约 6000+ 实例),顶点色 + onBeforeCompile 注入风摆
- 后期:MSAA HDR 合成 → UnrealBloom → 电影调色(暗角/色差/颗粒/饱和)→ ACES 输出
- 音频:WebAudio 全程序化合成(风、浪、车铃、收集音)
